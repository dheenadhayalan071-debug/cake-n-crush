# SEO implementation

Target geography: **Madurai, Tamil Nadu, India**. The site is built for local discovery, but
no ranking outcome is promised anywhere.

## Keyword themes → where they live

| Theme | Placement |
| ----- | --------- |
| cake shop in Madurai / bakery in Madurai | Home title & description, About description, footer, `Bakery` schema `areaServed` |
| celebration cakes in Madurai | Collection name, category blurb, menu metadata |
| eggless cakes in Madurai | `/menu?category=eggless`, collection page copy, menu metadata |
| custom cakes in Madurai | `/custom-cakes` title, description, H1-adjacent copy |
| chocolate cakes in Madurai | Derived `chocolate` collection, homepage chocolate-list block, menu metadata |
| 1kg / plum cakes | Collection pages, product schema offer names |

Copy is written for people first: no keyword stuffing, no hidden text, no doorway pages.

## Per-route metadata

`src/components/seo/Seo.jsx` sets, on every navigation: `<title>`, description, robots,
`theme-color`, Open Graph (`og:type`, `site_name`, `locale`, `title`, `description`, `url`,
`image`, `image:alt`), Twitter card, and `<link rel="canonical">` — all absolute, all derived
from `VITE_SITE_URL`.

| Route | Title | Intent |
| ----- | ----- | ------ |
| `/` | Cake N Crush — Patisserie & Celebration Cakes in Madurai | Brand + primary local terms |
| `/menu` | Our Menu — Cakes, Eggless Cakes & Plum Cakes in Madurai | Catalogue intent |
| `/gallery` | Gallery — Cakes & Creations from Cake N Crush, Madurai | Visual research |
| `/custom-cakes` | Custom Cakes in Madurai — Cake N Crush Cake Studio | High-value custom enquiry |
| `/about` | About Cake N Crush — Bakery & Cake Shop in Madurai | Trust |
| `/contact` | Contact & Location — Cake N Crush, Park Town, Madurai | "near me" intent |
| `/404` | Page not found | `noindex, follow` |

The static `<head>` in `index.html` carries the same defaults for crawlers that do not
execute JavaScript, plus a `<noscript>` block with the phone number, WhatsApp link and full
address so a non-JS visitor or crawler still gets the business essentials.

## Structured data

Emitted as JSON-LD by `<Seo>` per route (`src/lib/schema.js`).

- **`Bakery`** — name, description, url, telephone (`+918838159344`), image, address
  (street, locality, region, country), `areaServed: Madurai`, `hasMap` (Maps **search** URL
  built from the real address, not a claimed listing).
- **`WebSite`** — homepage only, linked to the bakery via `@id`.
- **`ItemList`** — the 18-cake catalogue with positions and deep links, on `/menu`.
- **`Product`** helpers (`productSchema`) — one `Offer` per variant with `price`,
  `priceCurrency: INR`, `availability: InStock`. Available for product pages if the
  catalogue later gets its own URLs.
- **`BreadcrumbList`** — every inner route.

**Deliberately absent:** `aggregateRating`, `review`, `reviewCount`, `openingHoursSpecification`,
`priceRange`. None are verified, and the content audit fails the build if they appear.

## Crawl & discovery

- `public/sitemap.xml` — 6 URLs, generated from the route list with `lastmod`, `changefreq`
  and priorities (`/` 1.0, `/menu` 0.9, `/custom-cakes` 0.9, `/contact` 0.8, `/gallery` 0.7,
  `/about` 0.6).
- `public/robots.txt` — allows everything (no private areas exist) and points at the sitemap.
- Both generated by `scripts/build-seo.mjs` from the same URL constant, so they cannot drift.
- `lang="en-IN"` on `<html>`, `<h1>` on every route, logical heading order, internal links
  from the footer to every collection.

## Performance as an SEO signal

- Initial JS ~85 kB gzip; each inner route 2–6 kB, lazy-loaded.
- CSS 11 kB gzip; images WebP with `srcset`; fonts preloaded and subset.
- No external requests, no blocking third-party scripts, no layout shift from images.
- Immutable caching for `/assets` and `/fonts`; security headers in `vercel.json`.

## Pre-launch SEO checklist

1. Buy the domain and set `VITE_SITE_URL` in Vercel; redeploy.
2. Verify `sitemap.xml` and `robots.txt` reference the live domain (`npm run seo` uses it).
3. Claim/create the Google Business Profile; add the verified listing URL to
   `business.js → googleBusinessUrl` if it should be linked.
4. Submit the sitemap in Google Search Console; request indexing for the six routes.
5. Add real product photography — image search and map-pack results depend on it.
6. If opening hours are confirmed, add them to `business.js` **and** to the `Bakery` schema.
7. Add verified reviews to `testimonials.js` before enabling any review markup.
